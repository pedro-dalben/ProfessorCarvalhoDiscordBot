# Configuração Discord

Registre os comandos na guild de teste com `DISCORD_COMMAND_REGISTRATION_MODE=guild`,
`DISCORD_DEV_GUILD_ID` e `DISCORD_ALLOWED_GUILD_IDS`. As respostas de identidade
são efêmeras. Use `IDENTITY_LINKING_ENABLED=true` apenas no ambiente local ou
controlado com `IDENTITY_LINK_CODE_PEPPER` definido.
